Exercise 10

Hover Board

Description

Design a single page that has at least five unique hover interactions. The interactions should experiment with different ideas and not repeat the same general idea. For example, if one hover changes the background color the next one shouldn't just change to a different background color. The content of the page should be a list of your top five favorite somethings. That could be your top five favorite songs, movies, places in the world, colors, etc.

The interactions should not be hidden.

Requirements

  • List of top five somethings
  • 5 unique hover interactions
  • 1440px wide
  • Page must scroll vertically
  • Has and uses columns

Things to Keep in Mind

  • This is more than a list
  • Try to avoid using images
  • Play with type

Objectives

  • Build hover interaction skill in Figma
  • Continue working with columns
  • Experiment with type

Final Submission

  • Turned in on time
  • All requirements met
  • Prototype link submitted on Canvas
  • Linked on your class index
